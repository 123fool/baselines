Create a clean, professional academic architecture diagram for a journal paper figure. White background, vector illustration style, English labels with some mathematical notation. High resolution, suitable for IEEE TMI / Medical Image Analysis publication.

## Overall Layout

Horizontal flow (left to right), three main rows:
- **Top row**: Main inference pipeline (Input → Encoding → Denoising → Decoding → Output)
- **Middle row**: Auxiliary model + conditioning details
- **Bottom row**: Training-only components and loss functions

Total figure size: approximately 18cm × 10cm (double-column journal width).

## Key Visual Emphasis

1. **Main data flow**: Thick blue arrows from left (Input MRI) to right (Predicted MRI)
2. **ControlNet conditioning**: Teal dotted lines from ControlNet to each UNet decoder level
3. **BTR bidirectional arrows**: Show forward (solid) and backward (orange dashed) clearly
4. **ET-BoN filtering**: Visually show N candidates being narrowed down to K survivors
5. **Innovation badges**: Small colored tags on innovation modules for quick identification
6. **Tensor shapes**: Annotated at key points (input, latent, output)
7. **Compact and readable**: All text should be legible at 100% zoom in a two-column journal layout

## Mathematical Notation to Include

- $x_{t_1}$: Baseline MRI at time $t_1$
- $\hat{x}_{t_2}$: Predicted follow-up MRI at time $t_2$
- $z_{t_1} = \mathcal{E}(x_{t_1})$: Encoded latent
- $c_{spatial} = [z_{t_1} \| \text{age}_{t_1}]$: Spatial condition (4ch or 6ch)
- $c_{ctx} = [\text{age}, \text{sex}, \text{dx}, v_1, ..., v_5]$: Cross-attention context
- $\mathcal{L} = \mathcal{L}_{fwd} + \lambda \mathcal{L}_{bwd}$: BTR loss
- ET-BoN: $N \to K$ candidate filtering at checkpoint step
