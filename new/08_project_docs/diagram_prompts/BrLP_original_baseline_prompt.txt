### SECTION 2: AUTOENCODER BRANCH (Blue Color Block)
**Position:** Left-center, vertically stacked sub-components
**Base Color:** Steel Blue (#4A6FA5) with BLUE border (no dashed, solid)
**Label:** "AutoencoderKL (AE)"

#### 2.1 Encoder
**Shape:** Trapezoid (narrowing downward)
**Label:** "Encoder"
**Details:**
- Conv3D blocks with residual connections
- Input channels: 1 (grayscale MRI)
- Feature pyramid: 64 → 128 → 128 → 128
- Output channels: 1
- Downsampling: 3× spatial downsampling (96 → 48 → 24 → 12)
- ResNet blocks: 2 per level
- Output: latent representation z_AE

**Tensor annotation on output:**
- z_AE shape: (B, 3, 12, 12, 12) 
- "3 latent channels, 8× spatial reduction"

#### 2.2 Latent Space
**Shape:** Horizontal bar, centered
**Label:** "Latent Code z_AE"
**Color:** Light teal (#B0E0E6)
**Size:** 120×40 px
**Content:**
- Equation: z_AE ~ N(μ, σ²)
- KL-divergence regularization applied during training
- "Compressed brain representation"
- Dimension: 3 channels × (12×12×12) spatial

#### 2.3 Decoder
**Shape:** Trapezoid (widening upward)
**Label:** "Decoder"
**Details:**
- Transposed Conv3D blocks with residual connections
- Upsampling: 3× spatial upsampling (12 → 24 → 48 → 96)
- Feature channels: 128 → 128 → 64 → 1
- Reconstruction output: MRI_reconstructed
- Skip connections from encoder (dotted blue lines from encoder to decoder)

**Output annotation:**
- Reconstructed MRI shape: (B, 1, 96, 96, 96)
- "Pixel-space brain reconstruction"
- Reconstruction loss: L_recon = MSE + L_perceptual

#### 2.4 Patch Discriminator (Side Component)
**Position:** Right side of AE block, smaller
**Shape:** Box with "D" label
**Color:** Dark blue (#1E3A8A)
**Label:** "Patch Discriminator (D)"
**Details:**
- Adversarial training component
- Classifies AE reconstructions as fake vs. real
- Input: reconstructed MRI; Output: patch-level discrimination scores
- Architecture: 3 layers of Conv3D with discriminator blocks
- Spatial dims (32, 32) patch classification
- Loss: L_adv = GAN loss (generator vs. discriminator)

**Connection:** 
- Double-headed arrow between Decoder output and Discriminator (adversarial feedback)
- Label on arrow: "L_AE_total = L_recon + λ×L_adv"

### SECTION 3: LATENT EXTRACTION & CONDITIONING PREPARATION
**Position:** Center-top transition zone
**Shape:** Process box with horizontal flow

**Step 1: Latent Extraction**
- Input: Baseline MRI, Follow-up MRI
- Process: z_baseline = Encoder(MRI_baseline), z_followup = Encoder(MRI_followup)
- Output annotation: Two parallel latent codes shown as "(B, 3, 12, 12, 12)" each

**Step 2: Covariate Encoding**
- Input: Disease progression covariates (cognitive scores, time delta Δt, MCI conversion risk)
- Process: Covariate concatenation and embedding
- Output: Context vector c ∈ ℝ^8 (cross-attention dimension)
- Annotation: "Context dim = 8 for cross-attention"

**Combined Input to Diffusion:**
- Concatenated vector: [z_baseline; z_followup; c_covariates]
- Used as conditioning for diffusion model

### SECTION 4: DIFFUSION MODEL BRANCH (Purple/Violet Color Block)
**Position:** Center-right, large vertical block
**Base Color:** Purple (#8B5CF6) with PURPLE border (solid)
**Title:** "Diffusion Model Pipeline"

#### 4.1 Noise Scheduler
**Position:** Top sub-component
**Shape:** Sine-wave curve visualization
**Label:** "DDIM Scheduler"
**Details:**
- Schedule type: scaled_linear_beta
- β_start = 0.0015, β_end = 0.0205
- Timesteps T = 1000 (training), T_infer = 50 (inference via DDIM)
- Visualize as a curve showing noise level over timesteps
- Annotation: "Deterministic reverse diffusion path via DDIM"

#### 4.2 Diffusion UNet (DiffusionModelUNet)
**Position:** Center of diffusion block (main component)
**Shape:** Nested U-shaped architecture (typical UNet depiction)
**Label:** "UNet (Diffusion Model)"
**Details:**

**Input to UNet:**
- Noisy latent z_t (at timestep t)
- Timestep embedding t_embed ∈ ℝ^256
- Cross-attention context c ∈ ℝ^8 (disease covariates)
- Conditioning embedding from previous latent

**Architecture:**
- **Encoder pathway (downsampling):**
  - Level 1: Conv3D (in=3, out=256) + ResBlock + Attention=False
  - Level 2: Conv3D (in=256, out=512) + ResBlock + Multi-head attention (512 heads)
  - Level 3: Conv3D (in=512, out=768) + ResBlock + Multi-head attention (768 heads)
  - Downsampling: maxpool 2×, strided convolutional layers

- **Bottleneck (middle):**
  - Residual blocks with transformer layers (1 transformer layer)
  - Cross-attention between latent features and covariate context
  - Maintains spatial resolution (12×12×12) at bottleneck

- **Decoder pathway (upsampling):**
  - Level 3: Transposed Conv3D (in=768, out=512) + ResBlock + Attention=True
  - Level 2: Transposed Conv3D (in=512, out=256) + ResBlock + Attention=True
  - Level 1: Transposed Conv3D (in=256, out=3) 
  - Upsampling: transposed convolutions with factor 2×

- **Skip Connections:**
  - Show as vertical dotted lines connecting encoder to decoder at each level
  - Label: "Skip connections preserve spatial features"

**Output:**
- Predicted noise ε_θ(z_t, t, c)
- Shape: (B, 3, 12, 12, 12) — same as input latent

**Parameter annotations on UNet:**
```
Channels: (256, 512, 768)
Attention levels: (False, True, True)
ResBlocks: 2 per level
Cross-attention dimension: 8
Transformer layers: 1
Upcast attention: True
Flash attention: False
```

#### 4.3 Denoising Loop
**Position:** Right side of UNet, showing iterative refinement
**Shape:** Circular loop with timestep counter
**Label:** "Iterative Denoising (t=T → t=1)"
**Details:**
- For each timestep t in reverse [T, T-1, ..., 1]:
  1. Predict noise: ε_pred = UNet(z_t, t, c)
  2. Scheduler step: z_{t-1} = Scheduler(ε_pred, z_t, t)
  3. Add stochasticity ≈ N(0, σ_t²) [optional, DDIM deterministic]
- Visualization: Show 3-4 intermediate denoising steps with noise decreasing
- Annotation: "DDIM: fewer steps (50) than training (1000), deterministic sampling"

**Position:** Bottom of entire diagram, parallel to main flow

- Integration: Auxiliary loss combined with main objectives: L_total = L_main + α×L_aux
- Activation timing: Typically trained jointly with diffusion model

**Connections:**

### SECTION 8: TRAINING PIPELINE (Optional Detail Box)
**Position:** Lower-right corner
**Shape:** Collapsible box with summary
**Title:** "Training Process Summary"

**Training Phases:**
1. **Phase 1: Autoencoder Training**
   - Loss: L_AE = L_recon + λ_adv × L_adversarial + λ_kl × L_kl_divergence
   - Duration: ~50-100 epochs
   - Output: Pre-trained autoencoder checkpoint

2. **Phase 2: Extract Latents**
   - Process: Apply trained encoder to all baseline+followup MRI pairs
   - Output: Latent codes for diffusion training

3. **Phase 3: Diffusion Model Training**
   - Loss: L_diffusion = E_t,z[||ε - ε_θ(z_t, t, c)||²]
   - Duration: ~200-300 epochs
   - Optimizer: Adam, LR=1e-4 with warmup
   - Batch size: 4-8 (limited by GPU memory)

4. **Phase 4: Joint Fine-tuning** (Optional)
   - ControlNet training on task-specific conditioning
   - Not present in original baseline

### SECTION 9: INFERENCE PIPELINE (Optional Detail Box)
**Position:** Lower-left corner, mirrored with training
**Shape:** Collapsible box
**Title:** "Inference Process"

**Step-by-step:**
1. Input baseline MRI + covariates
2. Encode: z_baseline = Encoder(MRI_baseline)
3. Prepare conditioning: covariates → embedding → context vector c
4. Initialize: z_T ~ N(0, I) — random initial latent
5. Loop: For t ∈ [T, T-1, ..., 1]
   - UNet predict noise: ε_pred = UNet(z_t, t, c)
   - DDIM step: z_{t-1} = Scheduler.step(ε_pred, z_t, t)
6. Decode: MRI_pred = Decoder(z_0)
7. Output: follow-up MRI prediction

**Timing annotation:** "Inference: ~5-10 seconds per sample (T_infer=50 steps)"

### SECTION 10: METRIC & LOSS ANNOTATION BOX
**Position:** Top-right, reference box
**Shape:** Information panel

**Key Equations:**
```
Reconstruction Loss:
L_recon = MSE(MRI_decoded, MRI_original)

KL Divergence (VAE):
L_kl = KL(q(z|x) || p(z)) = -0.5 Σ(1 + log(σ²) - μ² - σ²)

Adversarial Loss:
L_adv = -E[log D(MRI_fake)] + E[log(1 - D(MRI_real))]

Diffusion Loss:
L_diffusion = E_t[||ε - ε_θ(z_t, t, c)||²_2]

Total Training Loss:
L_total = L_recon + λ_adv·L_adv + λ_kl·L_kl + λ_aux·L_aux
```

**Validation Metrics:**
- Overall SSIM (Structural Similarity Index): target ≥ 0.89
- PSNR (Peak Signal-to-Noise Ratio): target ≥ 25 dB
- MAE (Mean Absolute Error): target ≤ 0.036
- ROI-focused SSIM: regional brain structures (hippocampus, etc.)

## SUMMARY

This diagram specification represents the **original BrLP baseline model** without any subsequent innovations (Innovation Points 1-5). The architecture combines:

1. **Variational Autoencoder (VAE)** for efficient 3D MRI compression (96³ → 12³ latent space)
2. **Adversarial training** via Patch Discriminator for perceptually realistic reconstructions
3. **Diffusion-based generative model** (UNet + DDIM scheduling) for longitudinal sequence synthesis
4. **Cross-attention conditioning** to incorporate disease progression covariates
5. **Auxiliary disease progression model** (Leaspy) for joint optimization of temporal dynamics

**Baseline Performance:** SSIM=0.8990 ± 0.0201, PSNR=25.22 dB, MAE=0.0356
**Optimal for:** 1-2 year follow-up MRI prediction in MCI-to-dementia conversion studies
