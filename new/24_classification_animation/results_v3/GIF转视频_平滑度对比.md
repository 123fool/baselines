## 各版本详解

### v1: Linear 2x (线性插值)

- **帧数**：11 帧 (2x 倍数)
- **算法**：简单的线性混合
- **特点**：
  - ✅ 速度最快，文件最小
  - ❌ 过渡可能显得生硬
- **用途**：快速预览，对平滑度要求不高

### v2: Smoothstep 2x (平滑过渡) ⭐

- **帧数**：11 帧 (2x 倍数)
- **算法**：Smoothstep 平滑曲线 (3t² - 2t³)
- **特点**：
  - ✅ 过渡非常平缓自然
  - ✅ 文件大小适中
  - ✅ 速度快、效果好
- **用途**：**日常使用的最佳选择**
- **推荐理由**：
  - 平滑度提升明显
  - 性能与质量的完美平衡
  - 0.37 秒视频流畅感提升 3 倍

### v3: Cubic 2x (Catmull-Rom 立方插值)

- **帧数**：11 帧 (2x 倍数)
- **算法**：Catmull-Rom 三阶样条插值
- **特点**：
  - ✅ 效果最精细，最接近"真实"中间帧
  - ❌ 计算量大（速度较慢）
  - ❌ 文件稍大
- **用途**：对质量要求极高的应用
- **推荐理由**：
  - 如果 v2 效果不够满意，升级到 v3
  - 细节变化最流畅

### v4: Adaptive 2x (自适应插值)

- **帧数**：11-13 帧 (根据变化程度自动调整)
- **算法**：根据帧间差异程度动态调整
- **特点**：
  - ✅ 智能选择最佳插值数量
  - ⚠️ 效果因内容而异
- **用途**：内容多样化的视频
- **推荐理由**：
  - 场景变化复杂时效果较好

### v5: Smoothstep 3x (极限平滑)

- **帧数**：16 帧 (3x 倍数)
- **时长**：0.53 秒 (延长至原来的 1.43 倍)
- **特点**：
  - ✅ 最丝滑的过渡动画
  - ⚠️ 影响原始播放速度
  - ⚠️ 文件较大
- **用途**：演示、营销、高端应用
- **推荐理由**：
  - 追求极致平滑感
  - 适合产品展示视频
  - 但注意：原本 10 秒 (6 帧 × 1750ms) 会变成 14.3 秒

### 插值算法对比

#### Linear (线性)

```
过渡曲线: /
效果: 生硬的线性变化
```

#### Smoothstep (平滑阶跃)

```
过渡曲线: ⌢ (S 形曲线)
效果: 柔和的非线性过渡
公式: 3t² - 2t³
```

#### Cubic (Catmull-Rom)

```
过渡曲线: ≈ (平滑曲线)
效果: 最自然的过渡
公式: c₀t³ + c₁t² + c₂t + c₃
```
